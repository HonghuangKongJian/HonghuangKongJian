#### ✨ Key Features of OctPc
- 🏆 **2.1+ Billion Points Capacity & 60 FPS Roaming**: Built on 64-bit spatial addressing and dynamic adaptive PagedLOD frustum culling. Handles massive point clouds with a memory footprint of just hundreds of megabytes.
- ⚡ **High-Speed Multi-Core Spatial Indexing (`octpc_cli`)**: Powered by an in-house 3D Morton Code linear octree algorithm with 16MB contiguous write buffering, achieving **8~10 Million Points/sec** spatial index throughput.
- 🖥️ **Out-of-the-Box 3D Interactive Viewer (`octpc_viewer`)**: Automatically invokes native Windows file dialogs; seamlessly converts raw `.las` files in the background; press `[F3]` anytime to switch point clouds.
- 🌐 **Bilingual Support (Zh / En)**: Built-in Chinese and English support for both `octpc_cli` and `octpc_viewer` with automatic OS locale detection and `--lang en` / `--lang zh` runtime toggles.
- 🎨 **Multi-Dimensional Color Modes & Distance Tuning**: One-click switching between True Color RGB, Intensity Grayscale, Semantic Classification, and Elevation Color Ramp.
- 📦 **Zero-Dependency Portable Distribution**: Pure standalone architecture completely free from heavy external dependencies such as PCL, Boost, Eigen, or MFC (~2.9 MB total size).
- 🔌 **Seamless GIS / Digital Twin Integration**: Ships with standard OSG dynamic driver plugin (`osgdb_octpc.dll`) for single-line loading and headless CLI pipeline automation.
