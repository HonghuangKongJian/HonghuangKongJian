#### ✨ OctPc 核心特性一览
- 🏆 **21 亿点超大容量支持与 60fps 满帧漫游**：基于 64 位文件寻址与自适应 PagedLOD 多级视锥分块调度技术，**单工程实装承载上限达 21.47 亿点**；前台按视距动态吞吐可见点，**常驻内存与显存仅需数百兆**，普通办公笔记本亦可畅享丝滑飞行动作；
- ⚡ **多核并行极速空间转换 (octpc_cli)**：采用自研 3D 莫顿码（Morton Code）线性八叉树核心算法与 16MB 连续写缓冲，核心空间编码与重排写入吞吐达 **800~1000 万点/秒**，半亿海量点云仅需数秒；
- 🖥️ **三维交互查看器开箱即用 (octpc_viewer)**：启动时自动唤起 Windows 原生文件浏览对话框；打开原始 `.las` 文件自动联动后台转换并呈现；运行中随时按 `[F3]` 切换点云；
- 🎨 **多维度科学赋色与视距微调**：原始真彩色 (RGB)、激光反射强度灰度、语义分类赋色与高程动态色带一键切换；支持实时调节点渲染大小与 LOD 视距倍率；
- 📦 **纯自包含免安装绿色分发**：彻底移除 PCL、Boost、Eigen、MFC 等依赖，全套套件解压即用（整体仅约 2.9 MB）；
- 🔌 **第三方测绘/GIS系统无缝集成**：配套提供标准 OSG 动态驱动插件（`osgdb_octpc.dll` 一行代码直接加载）与无头 CLI 管道自动化集成方案。
